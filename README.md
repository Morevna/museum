# Louvre Museum Landing Page 🏛️

A feature-rich, pixel-perfect responsive website for the Louvre Museum. This project demonstrates high-fidelity UI design implementation alongside advanced vanilla JavaScript interactive systems.

🔗 **[Live Demo](https://morevna.github.io/museum/)**

---

## 🛠️ Tech Stack & Architecture

- **Markup & Layout:** Semantic HTML5, CSS3 (Flexbox, Grid), BEM methodology.
- **Interactivity & Logic:** Vanilla JavaScript (ES6+), native DOM API.
- **External Web APIs:** Mapbox GL JS (customized markers and map styling).
- **Responsiveness:** Fluid adaptation for viewports down to 320px with zero horizontal scrolling.

---

## 🚀 Key Technical Features

- **Custom HTML5 Video Player:** Engineered an independent media player component from scratch. Built responsive custom UI controls for volume toggles, progressive tracking rails, playback rates, and fullscreen triggers synchronized with native HTMLMediaElement APIs.
- **Image Comparison Slider:** Developed an interactive "Before/After" slider component using mouse and touch event listeners, managing real-time dynamic clip-path adjustments.
- **Ticket Booking & Calculator Engine:** Created an integrated form architecture featuring reactive data binding that automatically recalculates aggregate totals based on selected ticket types and quantities. Included client-side form validation mechanisms.
- **Interactive Map Integration:** Linked and styled an interactive world map via the [Mapbox GL JS](https://mapbox.com) engine, implementing tailored branding, multi-coordinate geolocation pointers, and customized popup markers.
- **On-Scroll Fade Animations:** Utilized high-performance scroll triggers to execute elegant entrance animations for painting assets across the gallery viewport.
